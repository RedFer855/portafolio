# Portafolio · Fernando Barahona

Portafolio personal hecho con **HTML, CSS y JavaScript puro** (sin librerías) para la clase de Portales Web 2 – UNICAH.
Tiene un toque pixel art y a **Pixi**, un personaje que te acompaña mientras recorres la página.

- **Repositorio:** https://github.com/RedFer855/portafolio
- **Sitio publicado (GitHub Pages):** https://redfer855.github.io/portafolio/

## Contenido
- Foto de perfil, biografía y habilidades
- Proyectos generados desde un arreglo de objetos en JavaScript
- Contacto con formulario validado (abre tu app de correo con `mailto:`)
- Diseño responsive (mobile-first, breakpoints 720px y 1025px)

## Estructura
```
index.html
css/  base.css · layout.css · components.css · companion.css
js/   main.js · projects.js · companion.js · contactForm.js
media/
```

## Verlo en tu computadora
Abre la carpeta en VS Code y usa la extensión **Live Server**, o en una terminal:

```bash
python -m http.server 5500
```

y entra a http://localhost:5500
